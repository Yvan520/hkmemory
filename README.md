# Memory Mosaic · 香港記憶

> 每件產品背後，都有一個消失中的香港

一個記錄香港記憶嘅文化企劃。將香港嘅街頭美食、霓虹燈牌、老字號、叮叮車、粵語文化同舊區風貌，轉化為可以收藏嘅產品。

## 技術棧

- HTML5 / CSS3 / JavaScript
- Canvas 粒子系統
- Intersection Observer 動畫
- 3D 卡片傾斜交互
- 明暗主題切換

## 部署

本站使用 GitHub Pages 部署：https://yvan520.github.io/hkmemory/

## 本地開發

```bash
# 用任何靜態伺服器開啟
npx serve ./
# 或者直接用瀏覽器開啟 index.html
```
